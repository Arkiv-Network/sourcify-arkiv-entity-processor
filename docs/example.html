Capture, generation and comparison limits

These entities were generated locally from this API response; they were not fetched from deployed Arkiv. Stored mode reverses transport compression only; references remain visible. Hydrated mode is the actual output of the processor’s hydrate command. Bytecode payloads are shown as hex representing the actual bytes. Sample size figures distinguish decoded bytes, wire payload bytes and JSONL framing; they do not establish dataset savings.

This example uses the processor’s NDJSON input path. The API response does not contain the relational sourcifyIds carried separately by the Parquet adapter, so they are not fabricated here. One contract is evidence for this sample, not proof of full-dataset parity.

This live API response includes proxy information, which the processor preserves. The offline Parquet adapter does not provide live proxy resolution. The bundle uses an illustrative owner address; it is not evidence of contract ownership.
