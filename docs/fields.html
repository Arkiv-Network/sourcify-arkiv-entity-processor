Sourcify field → processor entity

Sourcify API names are comparison vocabulary here, not processor endpoints. Entity paths describe decoded payloads. Every supplied input field is preserved at the same path in verified_contract. Shared entities provide additional representations. Parquet adapter limitations below apply before processing; an API input preserves those fields when supplied.
