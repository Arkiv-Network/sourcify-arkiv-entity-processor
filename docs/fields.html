Sourcify field → processor entity

Sourcify API names are comparison vocabulary here, not processor endpoints. The paths below describe hydrated JSON, not direct offsets into the stripped stored envelope. Every supplied input field is restored at its original path. In stored v3 envelopes, data contains local values and references names the JSON Pointer destinations of shared values. Use the example explorer to inspect actual stored payloads. Parquet adapter limitations below apply before processing; an API input preserves those fields when supplied.
