Five entity kinds

Kind Purpose Schema / form Payload References / identity
verified_contract One verification/deployment record sourcify.verified-contract.v3 Envelope {schema, data, references}: contract-specific data and explicit references to shared values. Hydration restores the full original JSON. Original database IDs are supplementary sourcifycompilationid, sourcifydeploymentid, sourcifyverificationid and sourcifycontractid string attributes. compilationref is a typed key attribute; code-hash attributes index bytecode. The references manifest identifies shared data by kind and content hash, with exact destination JSON Pointer paths.
compilation Reusable compilation data sourcify.compilation.v3 Envelope {schema, data, references}: compiler settings, ABI, signatures, standard JSON, metadata, layouts, docs, source IDs and compiler-owned bytecode artifacts. Repeated source strings and bytecode are referenced. Sources and code are addressed by hashes. Compilation hash covers the complete canonical v3 envelope before spill. Deployment-specific bytecode does not belong in compilation identity.
sourcefile One unique source content sourcify.sourcefile.v1 JSON envelope {schema, content}. hash = SHA-256 of UTF-8 content, not the JSON wrapper.
code One unique bytecode body Binary body Raw bytes, application/octet-stream. hash = Keccak-256 of raw bytecode.
blob A slice of an oversized payload Binary slice Up to 100,000 raw bytes; hash, part, parts, size attributes. Parent $spill points to SHA-256 of the complete original body.

Indexed attributes and transport metadata

Attributes help locate entities; the hydrated record carries the complete data. A sentinel index value is not evidence that the source field was present. For example, unknown deployment block numbers have index value 0 while the payload retains null.

Attribute Type / value Meaning
projectid str:sourcify Dataset namespace.
kind str Entity category.
chainid / matchid / verifiedat u64 Query indexes; hydrated verifiedAt remains an ISO timestamp.
address / deployer addr Typed checksummed address attributes; the payload retains its source address.
compilationref key Verified-contract link to compilation.
hash / creationcodehash / runtimecodehash bytes32 Content hashes and query indexes.
contentencoding str:gzip or str:identity Explicit transport encoding.
originalcontenttype str Decoded JSON/text/binary media type.
payloadsha256 / stagingid bytes32 Payload integrity / semantic identity.
uploadschema str:sourcify-arkiv.upload.v1 Processor wire contract version.
