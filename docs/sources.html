Evidence behind these pages

This documentation belongs to the offline entity processor. Implementation statements describe the complete-input payload format in this checkout; they do not describe an application server. The source links below pin the earlier implementation used to generate the example; adapter changes in the current PR are covered by tests in this checkout. the capture and full-payload check are recorded in its provenance.

Processor implementation

  • source/prepare.ts — selects current Ethereum matches and referenced export rows
  • source/records.ts — maps export values into processor records
  • src/lib.rs — builds entities, hashes, references and spill parts
  • src/main.rs — writes the seed bundle and dispatches CLI commands
  • tests/ — real-data fixture and regression checks
  • README.md — operating instructions and bundle format

Processor PR #1 records the provenance and nullable-data fixes.

Reading the examples

The walkthrough uses a captured full Sourcify response for SafeProxy and entities generated from that response by the processor. The capture and validation record and reproduction instructions accompany the downloadable data. The field mapping is based on processor code. The findings distinguish stored values from information that would need later derivation or a different data source.
