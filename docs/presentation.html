Lossless shared storage · Processor v303 / 14
Sourcify → Arkiv03 · Separate the concerns

Which facts belong to one record?

RECORD-SPECIFIC

Where and how it was verified

  • Contract address and deployment
  • Match result and verification time
  • Changes between compiled and onchain code
REUSABLE CONTENT

What was compiled

  • Source files and compiler settings
  • ABI, metadata and compiler artifacts
  • Bytecode bodies that match exactly

Different addresses can point to the same shared content.

Lossless shared storage · Processor v304 / 14
Sourcify → Arkiv04 · Define the building block

An entity is a stored package.

ENTITY
KEYA unique handle for this entity
ATTRIBUTESLabels and indexes for finding it
PAYLOADThe data body: JSON or raw bytes

One job per package

A source-file entity stores source text.

A code entity stores bytecode bytes.

A compilation entity connects reusable compiler data.

A verification entity connects the complete record.
