What we preserve, and where parity stops

Entity parity is a data comparison. A successful import alone does not prove that every Sourcify field is represented.

Full input preservation

The decoded verified_contract payload equals the complete processor input as JSON. API records retain all supplied fields, nested structures and unknown extra fields without renamed keys or an injected schema marker. Shared entities and attributes remain supplementary indexes. This does not recover fields omitted before processing.

Parquet adapter coverage

  • Original IDs: sourcifyIds retains compilation, deployment, verification and contract IDs as strings; matchId remains its own field.
  • Nullable data: null ABI stays null, missing Solidity metadata stays null, and source-map values retain their available form.

These changes are in processor PR #1. Existing bundles are not updated in place; regenerate them to include the enriched payloads. The new full-input format changes all verified-contract keys and can increase bundle size and spill parts. Do not reuse old processed bundles.

Known limits

FindingConsequence
Snapshot scopeNew or changed upstream records require another export/import. There is no continuous synchronization.
Ethereum mainnet onlyPreparation selects source chain 1; transformation rejects other source chains. Destination Arkiv chain configuration does not add cross-chain source coverage.
Missing referencesThe source stream aborts on missing required dependencies unless --skip-missing-references is enabled, with skips capped by --max-skipped. The Compose pipeline enables bounded skipping by default. Skipped records are reported; missing metadata alone no longer causes a skip.
Signature tables excludedThe Parquet adapter omits signatures, stdJsonInput and stdJsonOutput. API input preserves these when supplied. Exact Parquet input preservation does not establish complete API parity.
No live proxy resolutionThe Parquet adapter supplies no current proxy resolution. Missing or empty resolution data remains unknown; no isProxy:false attribute is fabricated.
Bytecode null versus emptyThe verified_contract payload preserves null and 0x distinctly. Only supplementary shared code references collapse both to null.
Compiler-output fidelityAPI input preserves every supplied compiler-output field. The Parquet adapter supplies selected artifacts, not full compiler output or ASTs, and sets non-Solidity metadata to null.
Timestamp precisionThe Parquet adapter normalizes verification timestamps to UTC seconds, discarding fractional seconds.
Original bytes versus JSON valuesSource text is retained as content. Parsed and serialized metadata preserves represented values, not necessarily original whitespace, property order or an original IPFS artifact’s bytes.
Compilation hash definitionsThe indexed fingerprint is not a full compilation-payload hash. Full semantic staging identity controls deduplication. See hashes and storage.

What the evidence establishes

Processor tests cover nullable ABI and artifacts, original IDs, staging identity, chunking and deterministic output. The fixture compares a small set of real export rows with expected records and bundles. This is not a live comparison of every field in every Sourcify contract.

The contract example compares the complete captured API response with its decoded verified_contract payload. It does not establish complete Parquet-to-API parity.
