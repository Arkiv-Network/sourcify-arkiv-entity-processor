What we preserve, and where parity stops

Entity parity is a data comparison. A successful import alone does not prove that every Sourcify field is represented.

Fixes already in the processor

  • Original IDs: sourcifyIds retains compilation, deployment, verification and contract IDs as strings; matchId remains its own field.
  • Nullable data: null ABI stays null, missing Solidity metadata stays null, and source-map values retain their available form.

These changes are in processor PR #1. Existing bundles are not updated in place; regenerate them to include the enriched payloads. New payloads can have new entity keys.

Known limits

FindingConsequence
Snapshot scopeNew or changed upstream records require another export/import. There is no continuous synchronization.
Ethereum mainnet onlyPreparation selects source chain 1; transformation rejects other source chains. Destination Arkiv chain configuration does not add cross-chain source coverage.
Missing referencesThe source stream aborts on missing required dependencies unless --skip-missing-references is enabled, with skips capped by --max-skipped. The Compose pipeline enables bounded skipping by default. Skipped records are reported; missing metadata alone no longer causes a skip.
Signature tables excludedABI is retained, but signature-table-only information is not. Future ABI-derived signatures would not establish table parity.
No live proxy resolutionThe export is not a current view of proxy implementations. An empty resolution object means unknown; missing resolution does not produce an isProxy:false attribute.
Bytecode null versus emptyBoth null and 0x become null code references. This source distinction is not preserved in the entity graph.
Compiler-output fidelitySelected artifacts are retained, not every original compiler-output field or full AST. Non-Solidity metadata is set to null by the source adapter.
Timestamp precisionThe source adapter normalizes verification timestamps to UTC seconds, discarding fractional seconds.
Original bytes versus JSON valuesSource text is retained as content. Parsed and serialized metadata preserves represented values, not necessarily original whitespace, property order or an original IPFS artifact’s bytes.
Compilation hash definitionsThe indexed fingerprint is not a full compilation-payload hash. Full semantic staging identity controls deduplication. See hashes and storage.

What the evidence establishes

Processor tests cover nullable ABI and artifacts, original IDs, staging identity, chunking and deterministic output. The fixture compares a small set of real export rows with expected records and bundles. This is not a live comparison of every field in every Sourcify contract.

The next useful parity check is a matched source record and decoded entity graph, with a result for each field: equal, transformed, missing or outside scope.
